## 🚀 Featured Projects

- ✨ **[caelestia-ai-usage](https://github.com/ToraMutton/caelestia-ai-usage)**  
  A Python + QML widget that displays Claude and Codex subscription usage directly in Caelestia Shell.

- 🐦 **[fxtwitter-bot](https://github.com/ToraMutton/fxtwitter-bot)**  
  A Rust Discord bot that replaces X/Twitter links with FxTwitter embeds, generates sharing rankings, and optionally summarizes trends with Claude.

- 🤖 **[TORANOI](https://github.com/ToraMutton/local-ai-rocm)**  
  My local LLM environment powered by AMD Radeon, ROCm, Ollama, and OpenAI-compatible APIs.

- 🐧 **[dotfiles](https://github.com/ToraMutton/dotfiles)**  
  My customized Arch Linux environment built around Hyprland and Caelestia Shell.

- 🎨 **[ArToram](https://artoram.toramutton.me)**  
  A geometric art generator built with TypeScript, React, and the Canvas API.

- 🧊 **[Vextora](https://github.com/ToraMutton/minecraft-skin-editor)**  
  A browser-based Minecraft skin editor with a real-time Three.js 3D preview.

- 🌐 **[toramutton.me](https://toramutton.me)**  
  My personal website built with Astro, TypeScript, and Vercel.
